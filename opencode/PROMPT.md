Build a small GTK app that uses the Qwen3.8-27B model running right now in its inference paths. The inference engine then builds data to populate a "trading card" (like a Pokemon or Magic the Gathering card) demonstrating the power of the day and including SVG artwork illustration, stats, and fun facts about the day. Record everything you do, including this prompt, in a README.md in the project. When you're done, open the GTK app. Choose any programming language you wish from Rust to Python to C++ to even FORTRAN.
